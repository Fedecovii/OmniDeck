# OmniDeck
OmniDeck is a customizable desktop workspace that centralizes AI tools, graphic design software, and productivity applications in one interface. Add websites, launch installed apps, organize custom tabs, and personalize icons to create a cleaner, faster, and more efficient workflow.

**One hub. All your tools.**

AI Hub is a desktop application designed to centralize and simplify access to the tools used in digital work.

Organize your applications and web services in a single, clean, and customizable interface, reducing clutter and making your workflow faster and more efficient.

## Features

- AI Tools: Organize your favorite artificial intelligence tools.
- Graphic Tools: Manage applications for graphic design, video editing, and digital design.
- More Themed Sections: mockup sites, emulator, tool and more.
- Custom Shortcuts: Add websites and desktop applications using links or executable file paths.
- Personalization: Create and organize your own tabs according to your needs.
- Custom Icons: Customize your tools with your own icons.
- Quick Access: Launch websites and applications from a single hub.

## Vision

The goal is to create a unified, intuitive, and customizable digital workspace for designers, developers, content creators, and anyone who regularly uses multiple tools on their computer.

AI Hub is an evolving project, with new categories, features, and customization options planned for future releases.

## Status

Beta — Under Development
Alpha — Finished
The project is currently in the BETA stage. Features, interface, and organization are still being developed and improved.
